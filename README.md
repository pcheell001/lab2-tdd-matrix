
# Лабораторна робота №2

## Тема
Використання розробки на основі тестування (TDD).

## Мета
Ознайомитись з методикою розробки через тестування.

## Використані технології
- JavaScript
- Node.js
- Mocha
- Chai
- Git та GitHub

## Опис
Розроблено бібліотеку операцій над матрицями
із застосуванням підходу Test-Driven Development.

## Реалізовані операції
- Додавання матриць
- Віднімання матриць
- Множення матриць
- Транспонування матриць
- Перевірка сумісності розмірів

## Методологія TDD
Розробка здійснювалася за циклом:

1. RED — створення тесту, що не проходить.
2. GREEN — реалізація функціональності.
3. REFACTOR — покращення структури коду.

Історія комітів Git відображає етапи розробки.

## Встановлення

npm install

## Запуск тестування

npm test

## Результат
Розроблено бібліотеку операцій над матрицями
та створено 8 модульних тестів.
